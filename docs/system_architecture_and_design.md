# 《三角洲字點：特種識字部隊》(Project Delta Lexicon) 系統分析與設計白皮書

## 一、 專家團隊編制 (Required Expertise)
- 首席遊戲總監兼系統架構師 (Lead Game Director & System Designer)
- 教育科技與認知語言學家 (EdTech Specialist & Cognitive Linguist)
- 首席安全架構師與合規官 (Chief Information Security Officer & Child Compliance Lead)

- 語文教研專家 (Curriculum Content Specialist)

## 二、 戰術射擊與生字學習結合機制 (Gameplay & Gamification)
### 四階記憶階梯 (Memory Staircase)
1. **第一階（形音知覺辨識）**：CQB 遭遇戰突入，100~300ms 快速標定形似字弱點（「瘧」vs「虐」、「疾」vs「嫉」）。
2. **第二階（語意與部首解構）**：戰術破門雷射切割，部首組裝解密（「舟 + 倉 = 艙」）。
3. **第三階（脈絡詞彙串接）**：8 倍狙擊鏡風偏校準，成語語意長程壓制（「高聳峭壁」）。
4. **第四階（情境語用融合）**：C4 電子計時炸彈拆除，戰術引線依語用語境精確剪除。

## 三、 資訊安全與學生隱私保護 (InfoSec & Compliance)
- 嚴格遵循 COPPA、GDPR-K 與台灣個人資料保護法。
- 零 PII 收集架構，自動指派匿名戰術呼號（如 DELTA-07）。
- 伺服端權威防作弊架構，排除本機記憶體修改。
- 封閉式戰術語音輪盤，杜絕自由打字霸凌與個資外洩風險。

## 四、 平台評估與協作流
- 代碼託管與 CI/CD：GitHub Enterprise
- 教研與生字庫：Notion
- 玩法心流與白板：Miro
- 介面與字體走查：Figma
- 學生端發布：Web PWA / Cloudflare Pages / Vercel

## 五、 遺漏盲點與風險防制
- 普及級化：以非致命光子標記槍與語意修復取代血腥實彈。
- 認知負荷平衡：戰術子彈時間（Bullet Time）平衡操作與識字思考。
- 教師後台：xAPI 格式學習軌跡追蹤，一鍵匯出紙本戰術補給錯題單。
- 低階設備適配：純 Web / 輕量 WebGL 架構，支援各款 iPad 與平價 Chromebook。
