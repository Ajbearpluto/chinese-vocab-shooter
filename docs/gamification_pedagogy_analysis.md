# 國小國語科「生字圈詞」遊戲機制診斷與深度重構方案
> 角色定位：遊戲化設計顧問（Gamification Designer）× 十二年國教國語文教學專家

---

## 一、 教育遊戲痛點診斷與檢測指標

### 1. 傳統國語教育遊戲的 3 大核心致命傷
1. **機制剝離（Mechanical Segregation）**：跑酷/射擊到一半強制彈出選擇題，把答題當作「過路費」，摧毀心流。
2. **語意真空（Semantic Vacuum）**：符號消除連連看，脫離上下文與感情色彩，學童仍不會在寫作中造句。
3. **外在誘因陷阱（Extrinsic Motivation Trap）**：答錯倒扣星星，引發恐懼焦慮，缺乏內在探索樂趣。

### 2. 「好玩且有效」的 3 大企劃檢測指標
- **SLHI (語意敘事密合度)**：語詞字面含義/詞性是否 100% 等同於遊戲物理規律或技能效果。
- **FCR (心流連貫度)**：零彈窗、零純文字選擇題，操作即是語意理解過程。
- **IAD (自然習得驅力)**：為了打倒 Boss 或解開機關，主動去翻閱詞庫尋找相生相剋的詞彙。

## 二、 十二年國教「圈詞遊戲化」核心玩法設計

1. **玩法 A：【辭海工坊：語靈鍊成師】(Word-Alchemy)**
   - 偏正搭配（形容詞+名詞）鍊成探索道具；動賓搭配解鎖新地圖；語病搭配引發鍊金爆炸。
   - 對應課綱：2-Ⅲ-2 詞性與修辭、5-Ⅲ-3 語詞搭配慣例。
2. **玩法 B：【文境斷章：語脈構築戰】(Semantic Deckbuilder)**
   - 狀語起手蓄力 -> 動詞推進破綻 -> 名詞終結打擊；語境克制敵方情緒狀態。
   - 對應課綱：4-Ⅲ-2 感情色彩與語氣強度、5-Ⅲ-2 上下文推斷。
3. **玩法 C：【語境裂隙：造物冒險】(Contextual Terraforming RPG)**
   - 環境語境置換（如將「波濤洶湧」置換為「風平浪靜」開闢道路）。
   - 對應課綱：3-Ⅲ-1 語境細微差別辨析、6-Ⅲ-1 情境問題解決。

## 三、 遊戲機制修正對照表 (Before / After)

- **情境一：戰鬥場景**
  - Before: 彈出選擇題「請問聚精會神的意思？A.集中精神...」，點擊後扣怪物血。
  - After: Boss 進入「破綻百出」或「雜亂無章」狀態，玩家在 3 秒內用「井然有序」狙擊其弱點觸發擊飛硬直。
- **情境二：地圖探索**
  - Before: 走到格子跳出「春雨____了大地 (1)消耗 (2)滋潤...」選詞填空。
  - After: 荒地村民【奄奄一息】，玩家調配【滋潤】+【甘霖】覆蓋土地，長出參天大樹，物理演繹搭配後果。

## 四、 學習效益與動機評估機制 (Telemetry)

1. **ZPCP (零提示搭配精準度)**：不看提示直接命中正確搭配的比例，檢驗是否轉化為主動產出詞彙。
2. **SECR (語意試錯覆蓋率)**：出錯後是否能替換同義詞/近義詞，檢驗詞網概念集群深度。
3. **ORR (非強制重玩率)**：課後無作業要求下的自主啟動頻率。
4. **LCR (詞語圖鑑自發查閱頻率)**：為了研究配方而自發閱讀詞典的頻率。
